有限状态机（Finite State Machine，简称 FSM) 是在游戏开发中绕不开的设计模式。

qfgd 在 v0.1 版本就支持了 FSM，名字叫 EasyFSM。

与常见的 FSM 实现不同的是，EasyFSM 优先支持了链式 API。

我们来看下基本的用法。

## 基本使用

在任意场景任意节点编写如下脚本：

``` python
extends Node2D

# 使用枚举 定义 状态 Id
enum States
{
	Idle,
	Jump
}

# 定义状态机对象
var fsm:EasyFSM = EasyFSM.new()

func _ready() -> void:
	# 定义 idle 状态
	fsm.state(
		States.Idle
	).on_enter(func():
		print("idle state enter")
	).on_exit(func():
		print("idle state exit")
	)
	
	# 定义 jump 状态
	fsm.state(
		States.Jump
	).on_enter(func():
		print("jump state enter")	
	).on_exit(func():
		print("jump state exit")	
	)
	
	# 设置初始状态
	fsm.start_state(States.Idle)
	
func _process(_delta: float) -> void:
	
	if Input.is_key_pressed(KEY_1):
		print("数字 1 按下")
		fsm.change_state(States.Idle)
		
	if Input.is_key_pressed(KEY_2):
		print("数字 2 按下")
		fsm.change_state(States.Jump)

func _exit_tree() -> void:
	# 清空 fsm 对象
	fsm.clear()
	fsm = null

```

运行当前脚本，结果如下所示:
![](https://file.liangxiegame.com/ba82f126-303a-4446-9a69-e74c50f29b63.png)
因为我们通过 start_state 将 States.Idle 设置为初始状态，所以运行游戏后会先进入 Idle 状态。

此时我们按下数字 1，结果如下所示:

![](https://file.liangxiegame.com/6fdce346-6561-424b-b1d4-84f280da6235.png)
状态没有变更，因为我们写的代码是，在按下数字 1 时，要切换到 Idle 状态，但是此时已经是 Idle 状态，所以就不会走进入 Idle 状态的流程。

此时我们按下数字 2 结果如下:

![](https://file.liangxiegame.com/39fdefca-e7ae-4b89-8c5a-2cf22cf5d8c1.png)
成功切换到了 jump 状态。

在切换到 jump 状态之前，先退出了 idle 状态。
