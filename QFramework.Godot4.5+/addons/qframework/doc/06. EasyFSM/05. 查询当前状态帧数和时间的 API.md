笔者喜欢做一些震屏效果或者角色震动效果时使用帧数来实现，而有的时候需要使用时间和 lerp 函数写一些缓动效果，或者控制材质参数。

当然这种喜好并不是笔者一个人有的，笔者在翻阅一些其他引擎的插件或者项目源码看到过很多次这种使用方式，所以就"借鉴"走了。

而 EasyFSM 提供了进入当前状态后持续了多少帧和时间。

我们来看下基本使用。
## 基本使用

在任意场景任意节点，编写如下脚本:

``` python
extends Node2D

# 定义状态 Id
enum States
{
	Idle,
	Jump,
}

# 定义状态机
var fsm:EasyFSM = EasyFSM.new()

func _ready() -> void:
	# 定义 Idle 状态
	fsm.state(
		States.Idle
	).on_process(func(_delta:float):
		print("idle state current frame count:%d" % fsm.current_frames)
		print("idle state current seconds:%f" % fsm.current_seconds)
		
		# 计时一秒则跳转到 Jump 状态
		if fsm.current_seconds > 1.0:
			fsm.change_state(States.Jump)
	)
	
	# 定义 Jump 状态
	fsm.state(
		States.Jump
	).on_process(func(_delta:float):
		print("jump state current frame count:%d" % fsm.current_frames)
		print("jump state current seconds:%f" % fsm.current_seconds)
		
		# 计时一秒则跳转到 Idle 状态
		if fsm.current_seconds > 1.0:
			fsm.change_state(States.Idle)
	)
	
	# 置始状态
	fsm.start_state(States.Idle)

func _process(delta: float) -> void:
	# 驱动 process
	fsm.process(delta)
	
func _exit_tree() -> void:
	fsm.clear()
	fsm = null

```

代码的大体意思是，先进入 Idle 状态，一秒后跳转到 Jump 状态，一秒后再跳转到 Idle 状态，如此往复。
