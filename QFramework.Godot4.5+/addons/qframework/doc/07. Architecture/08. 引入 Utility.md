当然还是有一些问题，如果时候未来我们需要存储的数据非常多的时候，Model 层就会充斥大量存储、加载相关的代码。

还有就是，我们以后如果不想用 ConfigFile 了，而是想使用 json 或者 xml 甚至 sqlite 的时候，就会造成大量的修改工作量，会牵一发而动全身。

于是 QFramework 提供了一个 Utility 层，专门用来解决上述两个问题的，使用方法非常简单。
