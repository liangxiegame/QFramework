QFramework 架构是一套基于 MVC 的开发模式。

所以我们先从最熟知的 MVC 架构开始着手学习 QFramework 架构。

我们先做一个非常简单的计数器应用。

## 计数器应用准备

首先我们用 Godot UI 拼一个最简单的界面场景，如下所示:

![](https://file.liangxiegame.com/a7d1cc44-10f0-44eb-adc8-a4dd8ba6be49.png)

场景结构如下:

![](https://file.liangxiegame.com/94c196aa-b4fc-46e1-9815-8a25ed463af7.png)

在根节点我们编写脚本，代码如下：
``` python
extends Control

# controller
class_name CounterAppController

# view
@onready var btn_add: Button = $BtnAdd
@onready var btn_sub: Button = $BtnSub
@onready var count_label: Label = $CountLabel

# model
var count:int = 0

func _ready() -> void:
	# 监听输入
	btn_add.pressed.connect(func():
		# 交互逻辑
		count += 1
		# 表现逻辑
		_update_view()	
	)
	
	# 监听输入 
	btn_sub.pressed.connect(func():
		# 交互逻辑
		count -= 1
		# 表现逻辑
		_update_view()	
	)

func _update_view():
	count_label.text = "%d" % count

```

代码很简单，这是一个非常简易的 MVC 的实现。
