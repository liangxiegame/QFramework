我们看下当前的代码:

``` python
extends Control

# controller
class_name CounterAppController

# view
@onready var btn_add: Button = $BtnAdd
@onready var btn_sub: Button = $BtnSub
@onready var count_label: Label = $CountLabel

# model
var count:int = 0

func _ready() -> void:
	# 监听输入
	btn_add.pressed.connect(func(): 
		# 交互逻辑
		count += 1
		# 表现逻辑
		_update_view()	
	)
	
	# 监听输入 
	btn_sub.pressed.connect(func():
		# 交互逻辑
		count -= 1
		# 表现逻辑
		_update_view()	
	)

func _update_view():
	count_label.text = "%d" % count

```

目前的代码能运行，是完全没有问题的。

但是我们要用发展的眼光看待问题。

假如这是一个初创项目，那么接下来可能需要大量的业务逻辑。

其中很有可能让 count 在多个 Controller 中使用，甚至需要针对 count 这个数据写一些其他逻辑，比如增加 count 则增加 5 分，或者 count 需要存储等，总之 count 在未来可能会发展成一个需要共享的数据，而 count 目前只属于 CounterAppController，显然在未来是不够用的。

在实际项目开发中，只要秉持这够用即可的理念就可以应付大部分情况，不够用了就整理重构，而目前的情况是够用的，没必要做出任何改变。

不过为了演示项目架构的演化过程，就先假定当前的架构不够用了。

假定策划给了一个需求，这个需求分析下来，需要让 count 这个数据变成全局共享的。

如果不用 QFramework 解决方式很简单，直接创建一个自动加载（autoload）类或者场景，然后将 count 放在这个自动加载类中，或者将 count 改成静态（static）变量，总之至少有这两种方法。

接下来展示使用 QFramework 的解决方式，即引入架构（Architecture）。

## 引入架构

我们打开 QFramework 面板，或者按下 Ctrl + e 即可自动弹出 QFramework 面板，如图所示:
![](https://file.liangxiegame.com/7f3c4aa1-7f25-43d1-852a-d4dc28c2c9c1.png)

然后点击，创建 Architecture，打开创建架构面板，如图所示：
![](https://file.liangxiegame.com/87e8002e-8f26-4460-b286-12801f866ec1.png)

在名字栏输入 CounterApp，如图所示:

Autoload 名的意思是，创建架构之后，会将架构自动添加到 Godot 引擎的 Autoload （自动加载）中。

点击名字栏右边的创建按钮，就会创建脚本，并打开脚本，如图所示:

## 迁移 Count

接着我们将 CounterAppController 中的 count 迁移到 CounterAppArchitecture 中，代码如下:

``` python
class_name CounterAppArchitecture extends Architecture

# model
var count:int = 0

func init():
	pass
```

然后将 CounterAppController 中引用 count 的代码，修改成通过 CounterAppArchitecture 访问，代码如下:
``` python
extends Control

# controller
class_name CounterAppController

# view
@onready var btn_add: Button = $BtnAdd
@onready var btn_sub: Button = $BtnSub
@onready var count_label: Label = $CountLabel

func _ready() -> void:
	# 监听输入
	btn_add.pressed.connect(func(): 
		# 交互逻辑
		CounterApp.count += 1 # +-
		# 表现逻辑
		_update_view()	
	)
	
	# 监听输入 
	btn_sub.pressed.connect(func():
		# 交互逻辑
		CounterApp.count -= 1 # +-
		# 表现逻辑
		_update_view()	
	)

func _update_view():
	count_label.text = "%d" % CounterApp.count # +-

```

这样就迁移好了。
