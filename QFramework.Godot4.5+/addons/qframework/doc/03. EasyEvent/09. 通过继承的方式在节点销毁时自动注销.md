之前有聊过，自动注销的时机是 exit tree，为了改进这个问题，就在 qfgd v0.3.73 版本新增了 NodeWithDestroy 类，有了这个类，qfgd 就可以提供在节点销毁时自动注销的 API。

总共有两种方式实现在节点销毁时自动注销事件注册。

分别为

## 第一种 继承的方式 基本使用

新建一个场景，在场景的根节点下创建一个 Node 名字叫 EventReceiver 即事件接收者，如下:
![](https://file.liangxiegame.com/ff39fdad-7d3d-4342-b25a-c902b8ad0f10.png)

在根节点，我们创建一个脚本并定义一个静态事件，在按下空格后触发这个事件，代码如下:
``` python
extends Node2D

class_name EasyEventRealUnRegister

# 定义一个事件
static var some_event:EasyEvent = EasyEvent.new()

func _process(_delta: float) -> void:
	if Input.is_key_pressed(KEY_SPACE):
		print("空格键按下")
		some_event.trigger()

```

在子节点，也就是 EventReceiver 编写监听这个事件的代码。

我们通过继承的方式实现真正的自动注销，需要我们的脚本继承 EventWithDestroyEvent。

代码如下:
``` python
# 继承
extends NodeWithDestroyEvent

class_name EasyEventReceiver

func _ready() -> void:
	# 注册
	EasyEventRealUnRegister.some_event.register(func():
		print("on some event")
	).un_register_when_node_destroyed(self)
	
```

接着，我们需要在父节点的脚本获得子节点，并在按下数字 1 键，销毁子节点，父脚本如下:

``` python
extends Node2D

class_name EasyEventRealUnRegister

# 定义一个事件
static var some_event:EasyEvent = EasyEvent.new() # ++

# 获取
@onready var event_receiver: EasyEventReceiver = $EventReceiver

func _process(_delta: float) -> void:
	if Input.is_key_pressed(KEY_SPACE):
		print("空格键按下")
		some_event.trigger()
		
	# 按下 1 键，删除掉子节点
	if Input.is_key_pressed(KEY_1): # ++
		if event_receiver != null:
			event_receiver.queue_free()
			event_receiver = null

```

运行当前场景，按下空格键，结果如下:
![](https://file.liangxiegame.com/49974fc8-c46d-49d4-96af-8b4404c6729a.png)
接着我们将 子节点删除掉，按下数字 1 键，然后再按下空格键 结果如下：
![](https://file.liangxiegame.com/a1a1fb4c-94f8-494a-b047-67ab181fc609.png)
结果是正确的。
