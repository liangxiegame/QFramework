Godot 的信号必须依附于 Node 节点，不能定义为静态变量。

如果想要定义全局事件，需要创建一个 Node 脚本或者场景放到自动加载部分。

这样其实问题不大，但是有的时候一些全局事件与事件发生的系统或模块放在一起会更容易管理，这个时候把全局事件放到自动加载的方式就不够用了。

而 EasyEvent 可以直接作为静态变量定义，这样既可以在一个代码文件里管理全局事件，也可以把一些全局事件放在一些系统或模块的脚本里管理，会灵活很多。

我们看下全局事件的基本使用。
  
## 基本使用

在任意场景的任意节点上，编写如下代码:

``` python
extends Node2D

class_name EasyEventAsStaticVar

# 定义事件
static var event_a:EasyEvent = EasyEvent.new()

func _ready() -> void:
	
	# 注册事件
	event_a.register(func():
		print("event a:received")
	).un_register_when_node_exiting_tree(self)
	
	# 如果是在别的脚本可以通过类名.事件的方式访问
	EasyEventAsStaticVar.event_a.register(func():
		pass	
	).un_register_when_node_exiting_tree(self)

func _process(_delta: float) -> void:
	
	# 当空格键按下
	if Input.is_key_pressed(KEY_SPACE):
		event_a.trigger()

```

代码很简单，运行之后，按下空格键，结果如下:

将 EasyEvent 定义为静态变量，其实就是定义全局事件。

这种使用方式非常普遍。
