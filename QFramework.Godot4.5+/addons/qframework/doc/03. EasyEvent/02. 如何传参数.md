
EasyEvent 支持触发事件的时候传一个参数。

## EasyEvent 传参数

传参数的方式很简单，只需要在 trigger 的时候传参数即可，在注册事件的时候就可以接收到参数了。

代码示例如下：
``` python
extends Node2D

class_name EasyEventTriggerWithParam

# 定义事件
var event_a:EasyEvent = EasyEvent.new()

func _ready() -> void:
	
	# 注册事件
	# 注册时接收参数，可以带类型，可以不带类型
	# 带类型需要保证发送的时候类型一致
	# 不带类型则随意，但是不推荐这么用
	event_a.register(func(param:int): 
		print(param)
	).un_register_when_node_exiting_tree(self)
	
func _process(_delta: float) -> void:
	# 按下空格则触发事件
	if Input.is_key_pressed(KEY_SPACE):
		event_a.trigger(50)

```

代码很简单，挂到任意场景任意节点，运行之后，按下空格后，结果如下:
![](https://file.liangxiegame.com/5d1911ad-d683-4927-bc2a-e22e510ef031.png)
这样带参数的事件就发送成功了。

## 只能传一个或者不传参数

EasyEvent 只能传一个参数，或者不传参数。

如果一次事件触发要传多个参数怎么办？

答案是将事件参数定义为一个类。

这里我们再写一个示例，在任意场景和任意节点上，创建如下脚本:
``` python
extends Node2D

class_name EasyEventTriggerWithObj

# 定义事件 模拟当学生添加成功事件
var on_student_added:EasyEvent = EasyEvent.new()

# 定义学生对象，
class Student:
	var name:String
	var age:int
	
func _ready() -> void:
	# 注册事件
	on_student_added.register(func(student:Student):
		print("学生添加成功: 姓名 %s 年龄 %d" % [student.name,student.age])
	).un_register_when_node_exiting_tree(self)
	
func _process(_delta: float) -> void:
	
	# 当空格键按下时
	if Input.is_key_pressed(KEY_SPACE):
		
		# 定义要发送的数据
		var student = Student.new()
		student.name = "凉鞋"
		student.age = 33
		
		# 触发事件
		on_student_added.trigger(student)
```
运行之后，按下空格键，结果如下:
![](https://file.liangxiegame.com/9d49a427-954b-433b-b968-17554a6c775f.png)

运行成功了，代码虽然比之前多一点，但是不难。

## 参数数量与信号对比

Godot 自带的信号可以定义无限个参数。
而 EasyEvent 最多只能传一个参数。

传无限个参数会更自由，最多只能传一个参数，就要求我们把多个参数封装成一个类，会麻烦一点。

但是把参数封装成一个类是一个编码的好习惯，因为约束意味着代码更有条理、更有组织。

所以 EasyEvent 参数机制完全够用了。
