我们在开发 ui 的时候，经常会遇到一种情况，就是在界面初始化的时候需要更新一次界面，然后当要展示的数据发生变更还需要更新一次界面，使用伪代码展示如下:

``` python

func _ready():
	
	# 最开始更新一次界面
	_update_view()
	
	# 当数据发生变更时更新一次界面
	Events.on_some_data_changed.register(func():
		_update_view()
	).un_register_when_exiting_tree(self)
	
func _update_view():
	# 这里是一些更新界面的代码
	...
```

代码虽然没什么问题，但是 EasyEvent 提供了更简便的写法。

也就是使用 register_with_a_call 函数。

我们来练习一下。

## register_with_a_call 基本使用

在任意场景任意节点，挂上如下脚本:
``` python
extends Node2D

class_name EasyEventRegisterWithACall

# 定义事件
var event_a:EasyEvent = EasyEvent.new()

func _ready() -> void:

	# 注册事件，同时调用一次注册的函数	
	event_a.register_with_a_call(func():
		on_event_a()	
	).un_regisiter_when_node_exiting_tree(self)

func on_event_a():
	print("on event a:received")
	
func _process(_delta: float) -> void:
	# 当空格按下
	if Input.is_key_pressed(KEY_SPACE):
		
		print("空格键按下")
		# 触发事件 A
		event_a.trigger()

```

默认会调用一次 on_event_a()

当按下空格键后结果如下:
![](https://file.liangxiegame.com/75f54f74-a60e-407d-82aa-fba64ab7868d.png)

没有任何问题，代码也不难。

register_with_a_call 虽然在项目开发的过程中，使用频次不是很高。但是只要遇到了适合使用的场景，就可以减少很多冗余代码的编写工作，代码的可读性也会得到提升。
