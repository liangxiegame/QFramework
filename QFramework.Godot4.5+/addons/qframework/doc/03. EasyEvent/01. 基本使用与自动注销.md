任何引擎、平台、SDK，都会提供至少一种事件机制。

Godot 引擎提供的官方事件机制是信号（signal）。

而 qfgd 则提供的事件机制是 EasyEvent。

笔者先介绍一下 EasyEvent 的基本使用。

## EasyEvent 基本使用

我们创建任意一个场景，在场景的根节点编写如下代码:

``` python
extends Node2D

# 定义事件
var event_a:EasyEvent = EasyEvent.new()

func _ready() -> void:
	
	# 注册事件
	event_a.register(func():
		print("事件 A 触发")
	).un_register_when_node_exiting_tree(self) # 自动注销

func _process(_delta: float) -> void:
	
	# 当按下空格时
	if Input.is_key_pressed(Key.KEY_SPACE):
		# 触发事件
		event_a.trigger()

```

## 使用 EasyEvent 的好处：自动注销

我们可以在事件注册之后，通过 .un_register_when_node_exiting_tree(self) 来自动注销事件。

虽然大部分情况下，Godot 的信号会在发送者或者接收者销毁时自动取消关联，也就是自动取消，但是发生这种情况的前提是通过使用有名字的函数为前提，参考代码如下:
``` python
func _named_func():
	pass
	
some_signal_a.connect(_named_func) # self 或者 some_signal_a 所属对象销毁时会自动注销
```

如果使用的是匿名的函数，也就是 lambda 表达式或者是 callable，则会比较危险，参考代码如下:
``` python
some_singal_a.connect(func():pass) # 只有 some_signal_ 所属对象销毁时会自动注销，而如果当前脚本被销毁不会自动注销
```

所以在使用匿名函数和自定义信号的组合时，就会非常不可控。

很多情况下匿名函数非常好用。

这个时候使用 EasyEvent 则会在当前脚本销毁或者退出 tree 时，自动进行注销。
