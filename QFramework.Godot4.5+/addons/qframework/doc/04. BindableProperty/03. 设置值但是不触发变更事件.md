在使用 BindableProperty 的过程中，偶尔会遇到这样的需求，就是需要设置 BindableProperty 的值，但是不需要触发变更事件。

BindableProperty 通过一个 API 支持了这个功能。

我们看一下基本使用。

## 基本使用

在任意场景任意节点编写如下代码：

```python
extends Node2D

class_name BindablePropertySetValueWithoutEvent

# 定义
var some_number_property:BindableProperty = BindableProperty.new(0)

func _ready() -> void:
	# 注册
	some_number_property.register(func(number:int):
		print("some_number_property 变更:%d" % number)
	).un_register_when_node_exiting_tree(self)

func _process(_delta: float) -> void:
	# 当空格键按下
	if Input.is_key_pressed(KEY_SPACE):
		var random_number = randi_range(1,10)
		print("随机置了一个数字:%d" % random_number)
		# 设置值不触发变更事件
		some_number_property.set_value_without_event(random_number)
		
	# 当 1 键按下
	if Input.is_key_pressed(KEY_1):
		var random_number = randi_range(1,10)
		print("随机置了一个数字:%d" % random_number)
		# 设置值将触发变更事件
		some_number_property.value = random_number

```

代码很简单，大概意思是，按下空格则通过 set_value_without_event 设置值，按下数字 1 键则通过默认的方式设置值。

运行后按下空格键，结果如下:
![](https://file.liangxiegame.com/6f49c39c-1118-4a8f-983d-728ab032f535.png)
没有触发变更事件。

然后按下，数字 1 键，结果如下:
![](https://file.liangxiegame.com/28b7d6e0-da9b-47f8-9600-4db745e352c8.png)
触发了变更事件。
