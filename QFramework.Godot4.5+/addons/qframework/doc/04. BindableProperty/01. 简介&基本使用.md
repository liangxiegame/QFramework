在游戏开发过程中，我们经常要定义一些数据变量，比如生命值、魔法值、金币等。

当这些数据发生改变时，我们需要将这些数据展示到游戏界面上。

为了简化这部分工作，qfgd 支持了 BindableProperty。

## 简介

BindableProperty，意思是可绑定的属性。

BindableProperty 包含了一个数据变量，和一个数据变更事件。

当数据修改时，会触发数据变更事件，而这个数据变更事件其实就是 EasyEvent。

我们来看一下基本使用。

## 基本使用

我们创建一个场景，让场景的子节点包含一个 Label，如下图所示:
![](https://file.liangxiegame.com/8e0f24a1-e09c-409b-ab52-e22a0076b3d3.png)
在根节点创建脚本，代码如下:

``` python
extends Node2D

class_name BindablePropertyBasicUsage

# 定义金币
var coin:BindableProperty = BindableProperty.new(10)

# 金币 Label
@onready var coin_label: Label = $CoinLabel

func _ready() -> void:
	# 注册 coin 属性 当变更时会调用注册函数并把变更后的值传过来
	coin.register(func(c:int):
		print(c)
		coin_label.text = "金币:%d" % c
	).un_register_when_node_exiting_tree(self)

func _process(_delta: float) -> void:
	
	# 当按下空格时
	if Input.is_key_pressed(KEY_SPACE):
		# 金币值 + 1
		coin.value += 1

```

运行当前场景，当按下空格后结果如下:
![](https://file.liangxiegame.com/68edf942-0846-4812-a667-159fde10c27d.png)
显示结果如下:
![](https://file.liangxiegame.com/f7879513-7cec-4942-b53f-2bc2a1be43f4.png)

代码中的 coin 这个 BindablePropery 的数据值 直接更新到 CoinLabel 上了。
