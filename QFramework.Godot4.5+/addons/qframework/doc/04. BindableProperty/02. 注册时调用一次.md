与 EasyEvent 一样，BindableProperty 也支持注册时调用一次的功能。

## 基本使用
在任意场景，任意节点，编写如下代码:
``` python
extends Node2D

class_name BindablePropertyRegisterWithInitValue

# 定义事件
var coin:BindableProperty = BindableProperty.new(3)

func _ready() -> void:
	# 注册事件
	coin.register_with_init_value(func(c:int):
		print(c)	
	).un_register_when_node_exiting_tree(self)

```
运行之后，结果如下:
![](https://file.liangxiegame.com/efaeb9f4-542d-42cd-9e68-8376859da58d.png)
没有修改 coin 值，在场景运行之后直接输出了初始值 3，结果完全正确。

与 EasyEvent 不一样的是 API 名字是 register_with_init_value，在注册时，会通过注册函数的参数把初始值传过来。
