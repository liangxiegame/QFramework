事件除了当 ui 隐藏时自动注销，也支持 Node2D 和 Node3D 隐藏时自注销。

代码其实与 ui 隐藏自动注销差不多。

我们看下基本使用。

##  基本使用

创建一个 2D 场景，在根节点创建一个 3D 节点，如图所示：
![](https://file.liangxiegame.com/f2e2083a-abac-4812-bf5f-4519a739e32c.png))

在根节点创建脚本，代码如下:
``` python 
extends Node2D

var some_number:BindableProperty = BindableProperty.new(10)
var some_event:EasyEvent = EasyEvent.new()

@onready var node_3d: Node3D = $Node3D

func _ready() -> void:
	
	some_number.register(func(number:int):
		print("some number:%d" % number)
	).un_register_when_node_2d_hidden(self) # 自己需要是 Node2D
	
	some_event.register(func():
		print("some event")
	).un_register_when_node_3d_hidden(node_3d)


func _process(_delta: float) -> void:
	if Input.is_key_pressed(KEY_SPACE):
		print("空格键按下")
		some_number.value = randi_range(0,100)
		some_event.trigger()
	
	# 按下数字 1 则隐藏节点（会触发事件自动注销）
	if Input.is_key_pressed(KEY_1):
		self.hide()
		node_3d.hide()

```

运行之后，按下空格键，结果如下:
![](https://file.liangxiegame.com/88602a3e-2e7b-497a-9cfc-4e7f1826f36f.png)

按下 1 键，再按下空格键，结果如下:
![](https://file.liangxiegame.com/0fbb04b3-862a-4270-84dd-2a806903bc74.png)

结果是正确的。
