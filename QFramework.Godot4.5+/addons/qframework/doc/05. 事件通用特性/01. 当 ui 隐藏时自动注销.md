EasyEvent 和 BindableProperty 有很多一样的 API，为了节省篇幅，所以在这个专题统一进行介绍了。

在筹备 Godot 回合制案例的时候，遇到一种需求，就是当显示一个界面时候注册事件，然后当关闭一个界面时候需要注销事件，于是就诞生了 un_register_when_ui_hidden 这个 API。

我们来看下基本使用。


## 基本使用

创建一个 ui 场景，在根节点编写如下代码：

``` python
extends Control

# 定义
var some_event:EasyEvent = EasyEvent.new()
var some_number:BindableProperty = BindableProperty.new(10)

func _ready() -> void:
	some_event.register(func():	
		print("on some event")
	).un_register_when_ui_hidden(self) # self 只要继承 Control 就可以
	
	some_number.register(func(number:int):
		print("some number:%d" % number)	
	).un_register_when_ui_hidden(self)

func _process(_delta: float) -> void:
	
	# 按下空格键 触发事件
	if Input.is_key_pressed(KEY_SPACE):
		print("空格按下")
		some_event.trigger()	
		some_number.value = randi_range(0,100)
		
	# 按下数字 1 隐藏自己
	if Input.is_key_pressed(KEY_1):
		self.hide()
```

运行当前场景，按下空格键，结果如下:
![](https://file.liangxiegame.com/9e02f464-c7bf-41a2-8990-3c3e9e12936d.png)
事件正在触发，按下数字 1，之后再按下空格键，结果如下:
![](https://file.liangxiegame.com/3a569f0c-dc3c-4eab-bd8f-7a5218b884ac.png)

节点虽然隐藏了，但是 \_Process 函数还在继续执行，而此时按下空格键，则不触发事件了，因为事件随着节点的隐藏注销掉了。

这里虽然 API 后边是 ui_hidden，但是 ui 其实就是 Control 节点，任何继承了 Control 节点的子节点或者脚本都可以用这个 API。
